# Plot diagnostics for a regression model

Plot diagnostics for a regression model

## Usage

``` r
tl_plot_diagnostics(model, which = 1:4, ...)
```

## Arguments

- model:

  A tidylearn regression model object

- which:

  Which plots to create (1:4)

- ...:

  Additional arguments

## Value

A ggplot object (or list of ggplot objects)
