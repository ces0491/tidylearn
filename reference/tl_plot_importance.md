# Plot variable importance for tree-based models

Plot variable importance for tree-based models

## Usage

``` r
tl_plot_importance(model, top_n = 20, ...)
```

## Arguments

- model:

  A tidylearn tree-based model object

- top_n:

  Number of top features to display (default: 20)

- ...:

  Additional arguments

## Value

A ggplot object
