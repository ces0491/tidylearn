# Plot residuals for a regression model

Plot residuals for a regression model

## Usage

``` r
tl_plot_residuals(model, type = "fitted", ...)
```

## Arguments

- model:

  A tidylearn regression model object

- type:

  Type of residual plot: "fitted" (default), "histogram", "predicted"

- ...:

  Additional arguments

## Value

A ggplot object
